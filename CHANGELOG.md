# CHANGELOG

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-21

### Added
- Initial project setup and structure
- Flight booking functionality
- Flight tracking system
- Booking management interface
- Destinations listing page
- Customer care contact page
- Database schema with sample data
- API endpoints for flight and booking operations
- Responsive HTML/CSS frontend
- PHP backend integration
- Complete documentation (README, SETUP, CONTRIBUTING)

### Features
- Browse available flights
- Book flights with passenger details
- Track flight status in real-time
- View personal bookings
- Search destinations
- Contact customer support
- Responsive mobile design

### Technical
- HTML5 semantic markup
- CSS3 responsive design
- Vanilla JavaScript interactions
- PHP 7.0+ backend
- MySQL 5.7+ database
- RESTful API architecture
